繁體中文
1. 將 MacMP4.app 拖入 Applications（應用程式）。
2. 需要 Apple Silicon（M 系列）Mac 與 macOS 13 或以上。
3. 首次開啟會檢查 ffmpeg / ffprobe。已有 Homebrew 可在 App 中按「安裝 FFmpeg」。
   沒有 Homebrew 時提供官方安裝入口；Homebrew 目前正式支援 macOS 15 以上。
   也可自行安裝相容工具，返回 App 後自動重新檢查。手動指令：
   brew install ffmpeg
4. 這個版本尚未以 Apple Developer ID 簽署或經 Apple 公證。
   若 macOS 阻擋開啟，可先確認下載來源為 JimmyLC 的官方 GitHub Release，
   再依 macOS「系統設定 → 隱私權與安全性」的提示個別允許開啟。
   無須關閉 Gatekeeper 或系統安全功能。
5. 匯入影片、確認輸出位置，再按「開始轉檔」。原始影片會保留。

English
1. Drag MacMP4.app to Applications.
2. Requires an Apple Silicon Mac and macOS 13 or later.
3. First launch checks ffmpeg / ffprobe. With Homebrew, click Install FFmpeg in the app.
   Without Homebrew, setup links to its official website (currently supports macOS 15+).
   You can also install compatible tools separately. Returning to the app rechecks them.
   Manual command:
   brew install ffmpeg
4. This release is ad-hoc signed, without Developer ID signing or Apple notarization.
   macOS may block opening it. Verify the official JimmyLC GitHub Release source,
   then follow the per-app prompt in System Settings > Privacy & Security.
   Do not disable Gatekeeper or system security protections.
5. Add videos, review the output location, and start conversion. Originals are kept.
