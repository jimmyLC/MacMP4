MacMP4 v1.1.0：加入 Pro 終身版購買，並修正多項轉檔問題。

## 下載

- `MacMP4-v1.1.0-macos-arm64.dmg`：Apple Silicon（M 系列）Mac，macOS 13 以上。
- `SHA256SUMS.txt`：下載檔案的 SHA-256 校驗碼。

安裝方式與 v1.0.0 相同，詳見 DMG 內的 INSTALL.txt。此版仍使用本機 ad-hoc 簽章，**尚未使用 Apple Developer ID 簽署或經 Apple 公證**；macOS 可能阻擋首次開啟，確認來源為此官方 Release 後，依「系統設定 → 隱私權與安全性」的提示個別允許。

## 新功能

- **Pro 終身版（NT$90 一次買斷）**：在 App 內的「超級感謝」使用 Apple Pay 或信用卡購買，付款後自動啟用，並可用 Email＋序號在重裝後恢復。Pro 增加 Pro 標誌與淺色／深色／跟隨系統外觀；所有轉檔與裁切功能維持免費。目前商店只支援台灣發行的信用卡。
- 可選的首尾裁切與「強制 H.264」輸出（Free／Pro 皆可用）。

## 修正

- H.265 來源封裝後，輸出現在可在 QuickTime 播放（寫入 hvc1 標記）。
- 輸出到 exFAT 磁碟時，轉完但無法儲存的問題。
- 中途停止或中斷後，來源旁殘留隱藏暫存資料夾的問題；下次執行會自動清除。
- 多音軌影片現在會保留所有音軌，不再只留第一條。
- 同一批次中同名的輸出（例如 `a.ts` 與 `a.mkv`）不再互相覆蓋，改為 `a.mp4`、`a 2.mp4`。
- 批次轉檔中途切換選項，不再影響已排入佇列的檔案。
- 命令列：`--out` 資料夾不存在時自動建立，缺少參數時回報錯誤。

## 付款與隱私

付款資料由綠界處理，MacMP4 不儲存卡號。購買 Email 與序號加密保存於 Cloudflare D1，用於授權與重裝啟用；影片檔案不會上傳。詳見付款頁的隱私說明。
